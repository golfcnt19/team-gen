# สุ่มแบ่งทีม (Team Generator)

เว็บสุ่มแบ่งรายชื่อเป็นทีมอย่างยุติธรรม ทำงานบนเบราว์เซอร์ทั้งหมด ไม่ส่งข้อมูลไปที่ใด

- ใส่รายชื่อบรรทัดละ 1 คน (พิมพ์ `ชื่อ, 4` เพื่อกำหนดระดับทักษะได้เลย)
- แบ่งตามจำนวนทีม หรือจำนวนคนต่อทีม
- ปรับสมดุลทักษะ ★1–5 · คู่ที่ไม่ต้องการ (NG) · คู่บังคับ (Must) · หัวหน้าทีม · ผู้จัดงาน · ตั้งชื่อทีมเอง
- ผลลัพธ์: คัดลอกข้อความ / CSV / บันทึกรูป PNG
- บันทึก/โหลดรายชื่อไว้ในเบราว์เซอร์ (localStorage)

ไฟล์เดียว `index.html` ไม่มี dependency — เปิดในเบราว์เซอร์ได้ทันที
